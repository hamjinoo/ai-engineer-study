# AI Engineer Study

> AI Engineer / Applied AI Engineer 취업 준비를 위한 학습 기록 저장소입니다.  
> 단순히 공부한 내용을 모으는 것이 아니라, **직접 구현한 코드 · 오답 로그 · 회고 · 포트폴리오 근거**를 함께 쌓는 것을 목표로 합니다.

---

## 1. 이 저장소의 목적

이 저장소는 다음 목표를 위해 운영합니다.

1. Python, SQL, CS, API, Backend, AI/LLM/RAG 기초를 꾸준히 학습한다.
2. 매일 배운 내용을 코드와 문서로 남긴다.
3. 안 보고 구현할 수 있을 때까지 반복한다.
4. 학습 기록을 GitHub, README, 포트폴리오, 면접 답변으로 연결한다.
5. AI Engineer 취업 준비 과정을 증거 기반으로 정리한다.

---

## 2. 학습 운영 원칙

| 원칙 | 설명 |

| 정답보다 과정 | 틀린 코드, 헷갈린 부분, 수정 과정을 함께 기록합니다. |
