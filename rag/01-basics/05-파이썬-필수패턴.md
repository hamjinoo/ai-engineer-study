### append vs extend — "하나 넣기"와 "풀어서 이어붙이기"

```python
a = [1, 2]
b = [3, 4]

a.append(b)     # a = [1, 2, [3, 4]]   ← b가 통째로 "원소 하나"로 들어감 (리스트 안에 리스트!)
a.extend(b)     # a = [1, 2, 3, 4]     ← b 안의 원소들이 낱개로 풀려서 이어붙음
```

- `append(x)`: x **하나**를 그대로 넣는다. x가 리스트여도 "리스트라는 덩어리 하나"로 들어간다.
- `extend(리스트)`: 그 리스트 **안의 원소들**을 낱개로 풀어서 이어붙인다.

**함정 상황**: 함수가 dict 하나가 아니라 **dict가 여러 개 든 리스트**를 돌려줄 때(예: `chunk_fixed(...)`가 chunk dict 여러 개를 반환), 그 결과를 다른 리스트에 합칠 때 `append`를 쓰면 "리스트 안에 리스트"가 생겨버립니다.

```python
결과 = []
결과.append(chunk_fixed(text))   # ❌ 결과 = [ [dict1, dict2, dict3] ]  ← 원소 1개(리스트)
결과.extend(chunk_fixed(text))   # ✅ 결과 = [dict1, dict2, dict3]      ← 원소 3개(dict들)
```

이 실수를 하면 나중에 `결과[0]["text"]`처럼 dict인 줄 알고 접근하다가 `TypeError: list indices must be integers or slices, not str` 에러가 납니다 — "그 자리는 dict가 아니라 list였다"는 뜻이에요. **함수가 "여러 개(리스트)"를 돌려준다면 `extend`, "하나"를 돌려준다면 `append`** — 이 기준으로 고르면 됩니다.

### dict — 라벨 붙은 보관함 (이 프로젝트의 주력 자료구조)

dict = "라벨(키) → 내용물(값)" 보관함. **넣는 방법이 두 가지**입니다:

```python
# 방법 ① 한꺼번에 만들기 — 내용을 미리 알 때 (콜론 : 사용)
chunk = {"id": "doc-0", "text": "...", "start": 0}

# 방법 ② 하나씩 넣기 — 반복문으로 돌면서 채울 때 (콜론 없음!)
d = {}
d["청년"] = 1       # 없던 키면 새 칸이 생김  → {'청년': 1}
d["청년"] = 5       # 있던 키면 값을 덮어씀   → {'청년': 5}
```

⚠️ 헷갈림 포인트: 콜론(:)은 파이썬이 dict를 **보여줄 때** 그리는 표기입니다. 방법 ②로 넣을 때는 `d[키] = 값` 꼴이라 콜론이 안 보이지만, 결과는 똑같이 "키: 값"이 됩니다.

**꺼내는 방법도 두 가지**:

```python
d["청년"]           # 있으면 값. 없으면 프로그램이 죽음 (KeyError)
d.get("청년", 0)    # 있으면 값. 없으면 내가 정한 기본값(여기선 0) — 안 죽음
```

`.get(키, 기본값)` = "있으면 꺼내고, 없으면 이 값으로 쳐줘". 이 둘을 합친 게 **빈도 세기의 정석**:

```python
df[word] = df.get(word, 0) + 1
# 실행 순서(등호 오른쪽부터): ① 지금까지 몇이더라? (처음이면 0)  ② +1  ③ 그 칸에 다시 넣기
# → 읽고, 더하고, 다시 넣기 — 이 세 박자가 "세기"의 정체
```

### set — 중복을 자동으로 없애는 주머니

```python
set(["지원", "지원", "지원", "금액"])   # → {'지원', '금액'}   중복이 자동으로 사라짐!
"금액" in set(["지원", "금액"])          # → True              소속 확인이 매우 빠름
```

- `set(리스트)` = 리스트를 부으면 **중복이 제거된 주머니**가 나옵니다. 순서는 보장 안 됨 (순서가 필요하면 리스트).
- BM25 df의 "한 문서에 10번 나와도 손 한 번" 함정을 푼 게 바로 이것: `for word in set(tokens)`.
- 출력이 dict처럼 `{ }`로 생겼지만 구분법: **콜론(키: 값)이 있으면 dict, 없으면 set**.
- ⚠️ 빈 set은 `set()`이라고 써야 합니다 — `{}`는 빈 **dict**예요.

### input과 while True — 질문을 계속 받는 대화 루프

```python
while True:                                        # "무한히 반복해라"
    query = input("질문 입력 (q=종료): ").strip()    # 사용자가 친 글자 받기
    if query.lower() == "q":
        break                                      # 반복 전체를 끝냄
```

### 문자열/리스트 자르기 (슬라이싱)

```python
text[:500]      # 앞 500글자만 (긴 chunk 미리보기 출력)
text[2:5]       # 2번부터 4번까지 (5번은 미포함!)

chunks[:3]      # 리스트도 동일 — 상위 3개 (top-k!)

# 짝꿍 패턴: range(시작, 끝, 간격) — "위치들"을 건너뛰며 돌기 (chunking의 핵심 도구)
for start in range(0, 10, 3):
    print(start)          # 0, 3, 6, 9  (끝 10은 미포함)
```

⚠️ 문자열을 for로 직접 돌리면 **한 글자씩** 나옵니다 (`for ch in "안녕"` → 안, 녕). 덩어리로 자르고 싶다면 "글자를 순회"가 아니라 "range로 위치를 순회 + 슬라이스로 잘라오기" 조합입니다.

⚠️ **음수 인덱스 함정**: `text[-1]`은 "0보다 1 작은 자리"가 아니라 **"뒤에서 1번째"** 입니다. 그래서 `start - overlap`처럼 계산 결과가 음수가 될 수 있는 값을 슬라이스 앞자리에 넣으면, 에러 없이 조용히 **엉뚱한 위치(문서 끝쪽)에서 자르거나 빈 문자열**을 돌려줍니다 (`start=0`일 때 흔히 터지는 사고). 슬라이스에 변수를 넣기 전엔 그 변수가 음수가 될 수 있는지부터 의심하세요.
```python
text = "ABCDEFGHIJ"
text[-1:4]     # '-1'은 인덱스 9 → text[9:4] → 시작이 끝보다 뒤라서 빈 문자열 ''
```

### 정규식(re) — 지금은 "읽을 줄만" 알면 충분

정규식 = "글자 패턴 검색 미니 언어". 직접 설계할 일은 드물지만 코드에서 만나면 읽어야 합니다.

```python
import re
re.findall(r"[가-힣a-zA-Z0-9]+", "지원금액: 1억!")  # → ['지원금액', '1억']
#             └ "한글/영문/숫자가 1글자 이상 이어진 덩어리"를 전부 찾아라
re.findall(r"\d+", "만 39세, 창업 3년")             # → ['39', '3']
re.split(r"\n\n+", text)                            # 빈 줄 기준으로 텍스트 쪼개기
```

자주 보는 기호 4개만: `[가-힣]` 한글 한 글자 · `+` 1번 이상 반복 · `\d` 숫자 · `^` 줄의 시작.
그 이상을 만나면 "이 정규식 해석해줘"는 개념 설명이라 언제든 GPT에 물어봐도 됩니다.
