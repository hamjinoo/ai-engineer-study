# 01. AI 큰그림 — 아무것도 모르는 상태에서 시작하기

> 읽는 시점: Week 1. 15분이면 충분합니다. 외우려 하지 말고 지도만 머리에 넣으세요.

## 1. 용어들의 포함 관계

```
인공지능 (AI)  ─ 사람처럼 판단하는 소프트웨어 전부를 부르는 가장 큰 말
 └─ 머신러닝 (ML)  ─ 규칙을 사람이 코딩하지 않고, 데이터에서 "학습"시키는 방식
     └─ 딥러닝 (DL)  ─ 머신러닝 중에서 "신경망"이라는 구조를 아주 크게 쌓은 것
         └─ LLM (대형 언어 모델)  ─ 딥러닝으로 만든, 텍스트를 다루는 초대형 모델
             예: GPT, Claude, Gemini
```

여러분이 12주 동안 다루는 것은 이 중 **LLM을 갖다 쓰는 기술(RAG)** 과 **LLM이 만들어지는 원리(pretraining)** 딱 두 가지입니다. 나머지(이미지 인식, 추천 시스템, 강화학습...)는 몰라도 됩니다.

## 2. "학습"이란 무엇인가 — 웹 퍼블리셔 비유

퍼블리셔가 버튼을 만들 때는 규칙을 **직접** 씁니다.

```css
.button:hover { background: #0055ff; }   /* 사람이 규칙을 명시 */
```

머신러닝은 반대입니다. 규칙을 쓰는 대신 **예시를 잔뜩 보여주고, 규칙을 스스로 찾게** 합니다.

- 전통 프로그래밍: `입력 + 규칙 → 출력`
- 머신러닝: `입력 + 정답(출력) 잔뜩 → 규칙을 찾아냄`

여기서 찾아낸 "규칙"이 저장되는 곳이 **파라미터(parameter)** 입니다.

## 3. 모델 = 거대한 함수

모델은 신비한 존재가 아니라 그냥 **함수**입니다.

```python
출력 = model(입력)      # 이게 전부입니다
```

- 함수 안에는 숫자 손잡이(파라미터)가 수백만~수천억 개 있습니다.
- **학습(training)** = 예시 데이터를 보여주면서 이 손잡이들을 조금씩 돌려, 출력이 정답에 가까워지게 만드는 과정.
- **추론(inference)** = 학습이 끝난 함수에 새 입력을 넣어 출력을 받는 것. ChatGPT에 질문하는 것이 추론입니다.

> 💡 취업 포인트: "Applied AI Engineer"는 주로 **추론(이미 학습된 모델을 잘 쓰는 것)** 쪽 일을 합니다. 모델을 처음부터 학습시키는 건 연구자/빅테크의 일. 그래서 계획서의 포지셔닝이 "연구자가 아니라 적용하는 사람"인 겁니다.

## 4. LLM이 하는 단 한 가지 일

LLM의 본질은 놀랄 만큼 단순합니다.

> **"지금까지의 글을 보고, 다음에 올 토큰(글자 조각) 하나를 확률로 예측한다."**

"대한민국의 수도는" 다음에 뭐가 올까? → "서울"일 확률 92%, "부산" 1%, ... 이걸 한 토큰씩 반복하면 문장이 생성됩니다. 이게 전부입니다.

- 이 예측 능력을 만드는 과정 = **사전훈련(pretraining)** → `03-tiny-pretraining`에서 직접 만들어봅니다.
- 이 예측 능력에 내 문서를 물려주는 기술 = **RAG** → `02-gongo-rag`에서 직접 만들어봅니다.

자세한 건 [04-concepts/사전훈련-원리.md](../04-concepts/사전훈련-원리.md)에서.

## 5. 두 프로젝트가 어떻게 연결되는가

