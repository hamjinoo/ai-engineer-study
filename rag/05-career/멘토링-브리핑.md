## 2. 12주 계획 (요약)

- **메인 (55%)**: gongo-rag — 한국어 정부 공고문 RAG. 검색(BM25·임베딩)·생성·평가를 직접 구현하고, 골든셋 30~40문항으로 hit@k 측정, 실패를 검색/생성/데이터 문제로 분리 분석
- **서브 (25%)**: tiny-pretraining — 문자 단위 언어모델을 PyTorch로 밑바닥 구현 (tokenizer→loss→optimizer→sampling)
- **학습 원칙**: 핵심 알고리즘(chunking, BM25, cosine, hit@k)은 AI에게 맡기지 않고 직접 구현. AI는 개념 설명·코드 리뷰·힌트로만 사용
- 단계: W1~4 작게 완주 → W5~8 비교·평가 실험 → W9~12 정리·지원

## 3. 현재 위치 ([날짜] 기준, W[n])

- ✅ PDF 추출 파이프라인 + chunking 2종(고정 크기·문단 기반) 직접 구현 — 자가채점 테스트 5/5 통과
- ✅ **BM25 직접 구현**: 색인(df/avgdl)·IDF·score 완료 — 손계산 기대값(1.406)과 코드 결과 일치 검증. search 마무리 단계
- 파이썬은 사실상 이번에 처음 (주석 문법부터 시작) — 그래서 더디지만, 구현 하나하나를 손계산·증명 수준까지 이해하고 넘어가는 중
