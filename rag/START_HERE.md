## 작업하는 한 사이클

```text
RAG 전체지도에서 작업 하나 선택
→ Codex에 구현 범위와 완료 조건 전달
→ 테스트와 작은 입력으로 확인
→ 실험 파일에 숫자·실패·결정 기록
→ 체크하고 다음 작업으로 이동
```

AI에게 연결 코드·보일러플레이트·테스트 배관은 맡겨도 된다. 질문과 정답 검토, 실험 가설, 결과 해석, 최종 결론은 직접 판단한다.
