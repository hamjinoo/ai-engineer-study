# Retrospectives

Retrospectives 폴더는 주간/월간 회고를 저장하는 공간입니다.

---

## 목표

```text
- 매주 학습량과 산출물을 점검한다.
- 과부하 신호를 확인한다.
- 다음 주 핵심 승리 조건 3개를 정한다.
- 학습 내용이 포트폴리오로 이어지고 있는지 확인한다.
```
