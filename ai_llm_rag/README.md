# AI / LLM / RAG Track

AI / LLM / RAG 트랙은 목표 직무의 핵심 기술을 학습하고 구현하는 공간입니다.

---

## 목표

```text
- LLM API 호출 흐름을 이해한다.
- Prompt와 Response 구조를 다룬다.
- RAG의 chunking, embedding, retrieval, generation 흐름을 설명한다.
- 작은 문서 Q&A 시스템을 설계하고 구현한다.
- RAG 실패 원인과 평가 기준을 정리한다.
```

---

## 학습 예정

1. LLM API 기본 호출
2. Prompt / Response 구조
3. Token / Context Window
4. RAG 개요
5. Chunking
6. Embedding
7. Vector Search / Retrieval
8. Generation
9. Evaluation
10. Mini RAG Project
