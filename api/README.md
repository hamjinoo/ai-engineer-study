# API Track

API 트랙은 클라이언트와 서버가 데이터를 주고받는 방식을 이해하고, 직접 API를 설계하고 호출하는 능력을 만들기 위한 학습 공간입니다.

---

## 목표

```text
- HTTP 요청과 응답 구조를 설명한다.
- GET / POST / PATCH / DELETE를 상황에 맞게 사용한다.
- Status Code를 보고 성공/실패 원인을 추론한다.
- Header, Body, Query String, JSON을 구분한다.
- REST API 주소를 설계할 수 있다.
```

---

## 학습 예정

1. HTTP Method
2. Status Code
3. Header / Body
4. Query String / Path Parameter
5. JSON Request / Response
6. REST API 설계
7. 인증 토큰
8. API 에러 처리
