# SQL / DB Track

SQL / DB 트랙은 데이터를 저장하고 조회하는 능력을 만들기 위한 학습 공간입니다.

---

## 목표

```text
- 테이블 구조를 이해한다.
- SELECT, WHERE, JOIN, GROUP BY를 안 보고 작성한다.
- PK/FK로 테이블 관계를 설명할 수 있다.
- AI 서비스의 사용자 로그, 프롬프트, 응답, 평가 데이터를 DB로 설계할 수 있다.
```

---

## 학습 예정

1. SELECT / WHERE / ORDER BY / LIMIT
2. INSERT / UPDATE / DELETE
3. JOIN
4. GROUP BY / HAVING
5. PK / FK
6. 인덱스 기초
7. 트랜잭션 기초
8. AI 서비스용 로그 테이블 설계
