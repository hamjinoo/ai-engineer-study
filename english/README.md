# English Track

English 트랙은 개발자 영어와 면접 답변을 준비하기 위한 학습 공간입니다.

---

## 목표

```text
- 매일 짧은 개발자 영어 문장을 만든다.
- 내가 만든 프로젝트를 쉬운 영어로 설명한다.
- AI Engineer 면접에서 쓸 수 있는 기본 답변을 준비한다.
- 기술 문서를 읽는 데 필요한 기본 표현을 익힌다.
```

---

## 학습 예정

1. Basic Grammar Review
2. Daily Developer Sentences

4. Interview Answers
5. README English Summary
