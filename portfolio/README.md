# Portfolio Track

Portfolio 트랙은 학습 산출물을 취업용 증거로 정리하는 공간입니다.

---

## 목표

```text
- 학습 코드를 프로젝트 설명으로 바꾼다.
- 문제 정의, 해결 과정, 구현 내용, 트러블슈팅을 정리한다.
- 이력서 bullet point와 면접 답변으로 연결한다.
```

---

## 문서화 기준

각 프로젝트 또는 미니 과제는 아래 형식으로 정리합니다.

```markdown
# Project Name

## 문제 정의

## 왜 이 문제를 풀었는가

## 사용 기술

## 구현 기능

## 어려웠던 점

## 해결 과정

## 배운 점

## 다음 개선점

## 면접 답변 요약
```
