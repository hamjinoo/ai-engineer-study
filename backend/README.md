# Backend Track

Backend 트랙은 Python과 FastAPI를 기반으로 API 서버를 만들고, 데이터베이스와 AI 기능을 연결하는 능력을 만들기 위한 학습 공간입니다.

---

## 목표

```text
- FastAPI로 API 서버를 만든다.
- 요청과 응답 모델을 설계한다.
- DB와 연동한다.
- 인증, 에러 처리, 환경변수 관리를 적용한다.
- LLM API 또는 RAG 기능을 백엔드 서비스로 연결한다.
```

---

## 학습 예정

1. FastAPI 기본 라우팅
2. Request / Response Body
3. Pydantic 모델
4. DB 연결
5. 인증 기초
6. 에러 처리
7. 환경변수
8. Docker 실행
9. 미니 API 프로젝트
