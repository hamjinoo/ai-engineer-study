# Python Track

Python 트랙은 AI Engineer 학습의 기초입니다.

---

## 목표

Python을 단순히 문법으로 아는 것이 아니라, 아래 작업을 직접 할 수 있게 만드는 것이 목표입니다.

```text
- 데이터를 리스트와 딕셔너리로 표현한다.
- 조건과 반복으로 데이터를 처리한다.
- 반복되는 로직을 함수로 분리한다.
- JSON/API 응답 형태의 데이터를 Python으로 다룬다.
- 작은 CLI 또는 데이터 처리 프로그램을 만든다.
```

---

## 학습 순서

| Day | 주제 | 목표 |
|---:|---|---|
| Day 01 | List / Dict / Function | 공부 기록 데이터를 처리하는 기본 패턴 익히기 |
| Day 02 | Function / String | 문자열과 함수를 이용해 데이터 메시지 만들기 |
| Day 03 | File / Exception | 파일 저장과 에러 처리 익히기 |
| Day 04 | Module / CLI | 실행 가능한 작은 프로그램 구조 만들기 |
| Day 05 | JSON / API Data | API 응답 형태의 데이터 처리하기 |
| Day 06 | Mini Project | Study Log Analyzer 만들기 |
