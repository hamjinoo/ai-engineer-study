# CS Track

CS 트랙은 AI Engineer로 일할 때 필요한 컴퓨터와 서버의 작동 원리를 이해하기 위한 학습 공간입니다.

---

## 목표

```text
- 서버와 클라이언트가 어떻게 통신하는지 설명한다.
- 자료구조를 문제 상황에 맞게 선택한다.
- 운영체제, 프로세스, 포트, 로그의 기본 개념을 이해한다.
- 시스템 장애나 API 실패의 원인을 추론할 수 있다.
```

---

## 학습 예정

1. 네트워크 / HTTP
2. 자료구조
3. 알고리즘 기초 / Big-O
4. 운영체제 / Linux
5. 프로세스 / 스레드
6. 포트 / 로그 / 환경변수
7. Docker 기초
8. 시스템 디자인 기초

---

## AI Engineer 연결 포인트

CS는 단순 이론이 아니라 AI 시스템을 운영하고 디버깅하기 위한 기반입니다. FastAPI 서버, RAG 파이프라인, LLM API 호출, Docker 배포, 로그 확인과 모두 연결됩니다.
